# About

Infer normal maps directly in browser. Powered by [MoGe](https://github.com/microsoft/MoGe) v2 and previewed with [three.js](https://github.com/mrdoob/three.js). Try it at [MoGe-web](https://ycw.github.io/MoGe-web) app, created by [@ycwhk](https://x.com/ycwhk).

The model `moge-2-vits-normal-onnx.onnx` is taken directly from [Ruicheng/moge-2-vits-normal-onnx](https://huggingface.co/Ruicheng/moge-2-vits-normal-onnx). It is included here without any modifications or quantization.
