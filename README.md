# About

Infer normal maps directly in browser. Powered by [MoGe](https://github.com/microsoft/MoGe) v2 and previewed with [three.js](https://github.com/mrdoob/three.js). Try it at [MoGe-web](https://ycw.github.io/MoGe-web) app, created by [@ycwhk](https://x.com/ycwhk).

The model `moge-vits-normal-fp16.onnx` is an FP16 quantized version derived from the original FP32 model at [Ruicheng/moge-2-vits-normal-onnx](https://huggingface.co/Ruicheng/moge-2-vits-normal-onnx), offering faster load times and lower memory usage in the browser.
